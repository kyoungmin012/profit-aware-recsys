# profit-aware-recsys
# 수익성 인지 추천 시스템
이커머스 행동 로그로 매출 손실을 찾고, 정확도와 이익의 균형점을 설계한다.

## 문제 정의
이커머스에서 장바구니 이탈로 새는 매출을 계산해 어떤 부분을 개선할지 우선순위를 정하고,
상품 추천으로 정확도와 이익 사이의 최적점을 제안한다.

| 의사결정자 | 결정할 것 | 이 프로젝트가 주는 답 |
| --- | --- | --- |
| 그로스·기획팀 | 어디를 먼저 개선할까 | 세그먼트별 매출 기회 규모 순위 |
| MD·추천팀 | 추천 영역에 무엇을 보여줄까 | 정확도 vs 기대 공헌이익 트레이드오프와 권장 λ |

## 성공 기준
- 1부: 매출 기회 1순위 세그먼트를 금액과 근거로 제시한다.
- 2부: 정확도 손실을 일정 수준 이내로 묶으면서 기대 공헌이익이 오르는 λ를 제시한다.
- 회복률·마진율 가정을 바꿔도 결론이 유지되는지 확인한다.

## 하지 않는 것
- 쿠폰·추천의 실제 효과(인과)는 이 데이터로 알 수 없으므로 단정하지 않고, A/B 테스트 설계로 대신한다.
